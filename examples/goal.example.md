# Training goal (example)

Copy to `$MEMORY_DIR/fitness/goal.md` and rewrite it in your own words. The
WOD skills read this file to decide what to program and when.

## Goals

1. Get stronger on the basic lifts (squat, press, row, deadlift).
2. Build some muscle (hypertrophy-friendly volume).
3. Keep a decent aerobic base.

## Mindset

- I like the CrossFit format: a different WOD every day, AMRAP and EMOM.
- I want to see small, continuous, measurable progress.
- Longevity beats performance: no training to failure.

## Background

- Some past running experience, new to barbell training.

## Constraints

- Sessions on weekdays only; nothing planned on weekends.
- Sessions must fit a 45-minute slot, warm-up and cool-down included.
- Thursday: light aerobic run only (another sport in the evening).
- Use only AMRAP and EMOM formats so session length is predictable.
